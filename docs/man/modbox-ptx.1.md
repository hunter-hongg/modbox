# NAME

modbox-ptx - Produce permuted index of file

# SYNOPSIS

**modbox ptx** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Produce permuted index of file. This is the modbox implementation of the standard ptx utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
