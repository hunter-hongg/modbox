# NAME

modbox-lsblk - List block devices

# SYNOPSIS

**modbox lsblk** [*OPTION*]... [*ARG*]...

# DESCRIPTION

List block devices. This is the modbox implementation of the standard lsblk utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
