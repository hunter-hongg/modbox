# NAME

modbox-ip - Show / manipulate routing, devices and tunneling

# SYNOPSIS

**modbox ip** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Show / manipulate routing, devices and tunneling. This is the modbox implementation of the standard ip utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
