# NAME

modbox-time - Time a command

# SYNOPSIS

**modbox time** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Time a command. This is the modbox implementation of the standard time utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
