# NAME

modbox-stty - Change terminal line settings

# SYNOPSIS

**modbox stty** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Change terminal line settings. This is the modbox implementation of the standard stty utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
