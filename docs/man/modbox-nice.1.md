# NAME

modbox-nice - Run command with modified scheduling priority

# SYNOPSIS

**modbox nice** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Run command with modified scheduling priority. This is the modbox implementation of the standard nice utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
