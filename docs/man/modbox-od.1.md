# NAME

modbox-od - Dump files in octal and other formats

# SYNOPSIS

**modbox od** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Dump files in octal and other formats. This is the modbox implementation of the standard od utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
