# NAME

modbox-prompts - Manage shell prompts

# SYNOPSIS

**modbox prompts** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Manage shell prompts. This is the modbox implementation of the standard prompts utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
