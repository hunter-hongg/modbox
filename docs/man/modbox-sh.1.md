# NAME

modbox-sh - Shell command interpreter

# SYNOPSIS

**modbox sh** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Shell command interpreter. This is the modbox implementation of the standard sh utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
