# NAME

modbox-pathchk - Check file and directory names

# SYNOPSIS

**modbox pathchk** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Check file and directory names. This is the modbox implementation of the standard pathchk utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
