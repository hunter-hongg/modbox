# NAME

modbox-printf - Format and print data

# SYNOPSIS

**modbox printf** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Format and print data. This is the modbox implementation of the standard printf utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
