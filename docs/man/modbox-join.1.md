# NAME

modbox-join - Join lines of two files on a common field

# SYNOPSIS

**modbox join** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Join lines of two files on a common field. This is the modbox implementation of the standard join utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
