# NAME

modbox-numfmt - Convert numbers from/to human readable format

# SYNOPSIS

**modbox numfmt** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Convert numbers from/to human readable format. This is the modbox implementation of the standard numfmt utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
