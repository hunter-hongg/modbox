# NAME

modbox-mknod - Make block or character special files

# SYNOPSIS

**modbox mknod** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Make block or character special files. This is the modbox implementation of the standard mknod utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
