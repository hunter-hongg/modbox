# NAME

modbox-setfacl - Set file access control lists

# SYNOPSIS

**modbox setfacl** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Set file access control lists. This is the modbox implementation of the standard setfacl utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
