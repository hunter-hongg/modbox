# NAME

modbox-tty - Print name of terminal

# SYNOPSIS

**modbox tty** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Print name of terminal. This is the modbox implementation of the standard tty utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
