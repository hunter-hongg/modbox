# NAME

modbox-tsort - Topological sort

# SYNOPSIS

**modbox tsort** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Topological sort. This is the modbox implementation of the standard tsort utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
