# NAME

modbox-top - Display processes

# SYNOPSIS

**modbox top** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Display processes. This is the modbox implementation of the standard top utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
