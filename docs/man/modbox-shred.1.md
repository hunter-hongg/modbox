# NAME

modbox-shred - Securely delete files

# SYNOPSIS

**modbox shred** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Securely delete files. This is the modbox implementation of the standard shred utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
