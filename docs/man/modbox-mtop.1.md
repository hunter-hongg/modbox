# NAME

modbox-mtop - Monitor top

# SYNOPSIS

**modbox mtop** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Monitor top. This is the modbox implementation of the standard mtop utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
