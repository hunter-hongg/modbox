# NAME

modbox-pr - Convert text files for printing

# SYNOPSIS

**modbox pr** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Convert text files for printing. This is the modbox implementation of the standard pr utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
