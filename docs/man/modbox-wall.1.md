# NAME

modbox-wall - Write message to all users

# SYNOPSIS

**modbox wall** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Write message to all users. This is the modbox implementation of the standard wall utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
