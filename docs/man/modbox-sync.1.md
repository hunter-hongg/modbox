# NAME

modbox-sync - Flush file system buffers

# SYNOPSIS

**modbox sync** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Flush file system buffers. This is the modbox implementation of the standard sync utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
