# NAME

modbox-shuf - Generate random permutations

# SYNOPSIS

**modbox shuf** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Generate random permutations. This is the modbox implementation of the standard shuf utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
