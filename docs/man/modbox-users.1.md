# NAME

modbox-users - Print users currently on system

# SYNOPSIS

**modbox users** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Print users currently on system. This is the modbox implementation of the standard users utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
