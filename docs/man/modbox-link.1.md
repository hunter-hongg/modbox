# NAME

modbox-link - Make links between files

# SYNOPSIS

**modbox link** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Make links between files. This is the modbox implementation of the standard link utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
