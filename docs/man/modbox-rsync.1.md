# NAME

modbox-rsync - Fast incremental file transfer

# SYNOPSIS

**modbox rsync** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Fast incremental file transfer. This is the modbox implementation of the standard rsync utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
