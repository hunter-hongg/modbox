# NAME

modbox-lscpu - Display CPU architecture information

# SYNOPSIS

**modbox lscpu** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Display CPU architecture information. This is the modbox implementation of the standard lscpu utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
