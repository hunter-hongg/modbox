# NAME

modbox-nslookup - Query Internet name servers

# SYNOPSIS

**modbox nslookup** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Query Internet name servers. This is the modbox implementation of the standard nslookup utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
