# NAME

modbox-true - Do nothing, successfully

# SYNOPSIS

**modbox true** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Do nothing, successfully. This is the modbox implementation of the standard true utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
