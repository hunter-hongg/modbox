# NAME

modbox-runcon - Run command with SELinux context

# SYNOPSIS

**modbox runcon** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Run command with SELinux context. This is the modbox implementation of the standard runcon utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
