# NAME

modbox-split - Split files into pieces

# SYNOPSIS

**modbox split** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Split files into pieces. This is the modbox implementation of the standard split utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
