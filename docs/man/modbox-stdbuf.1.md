# NAME

modbox-stdbuf - Run command with modified stdio buffer size

# SYNOPSIS

**modbox stdbuf** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Run command with modified stdio buffer size. This is the modbox implementation of the standard stdbuf utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
