# NAME

modbox-test - Evaluate conditional expressions

# SYNOPSIS

**modbox test** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Evaluate conditional expressions. This is the modbox implementation of the standard test utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
