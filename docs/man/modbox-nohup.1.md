# NAME

modbox-nohup - Run command immune to hangups

# SYNOPSIS

**modbox nohup** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Run command immune to hangups. This is the modbox implementation of the standard nohup utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
