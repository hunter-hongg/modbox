# NAME

modbox-logname - Print login name

# SYNOPSIS

**modbox logname** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Print login name. This is the modbox implementation of the standard logname utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
