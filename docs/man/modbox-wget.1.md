# NAME

modbox-wget - Retrieve files from web

# SYNOPSIS

**modbox wget** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Retrieve files from web. This is the modbox implementation of the standard wget utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
