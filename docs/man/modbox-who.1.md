# NAME

modbox-who - Who is on the system

# SYNOPSIS

**modbox who** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Who is on the system. This is the modbox implementation of the standard who utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
