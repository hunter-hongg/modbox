# NAME

modbox-ss - Show sockets

# SYNOPSIS

**modbox ss** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Show sockets. This is the modbox implementation of the standard ss utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
