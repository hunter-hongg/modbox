# NAME

modbox-rev - Reverse lines characterwise

# SYNOPSIS

**modbox rev** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Reverse lines characterwise. This is the modbox implementation of the standard rev utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
