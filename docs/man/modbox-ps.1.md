# NAME

modbox-ps - Report process status

# SYNOPSIS

**modbox ps** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Report process status. This is the modbox implementation of the standard ps utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
