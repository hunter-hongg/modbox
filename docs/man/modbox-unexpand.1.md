# NAME

modbox-unexpand - Convert spaces to tabs

# SYNOPSIS

**modbox unexpand** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Convert spaces to tabs. This is the modbox implementation of the standard unexpand utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
