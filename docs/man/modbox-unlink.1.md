# NAME

modbox-unlink - Call unlink on file

# SYNOPSIS

**modbox unlink** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Call unlink on file. This is the modbox implementation of the standard unlink utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
