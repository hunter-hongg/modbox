# NAME

modbox-lsc - List command

# SYNOPSIS

**modbox lsc** [*OPTION*]... [*ARG*]...

# DESCRIPTION

List command. This is the modbox implementation of the standard lsc utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
