# NAME

modbox-tac - Concatenate and display files in reverse

# SYNOPSIS

**modbox tac** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Concatenate and display files in reverse. This is the modbox implementation of the standard tac utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
