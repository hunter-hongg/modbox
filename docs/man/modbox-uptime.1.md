# NAME

modbox-uptime - Tell how long system is up

# SYNOPSIS

**modbox uptime** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Tell how long system is up. This is the modbox implementation of the standard uptime utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
