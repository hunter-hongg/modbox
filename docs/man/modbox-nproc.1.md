# NAME

modbox-nproc - Print number of processing units

# SYNOPSIS

**modbox nproc** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Print number of processing units. This is the modbox implementation of the standard nproc utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
