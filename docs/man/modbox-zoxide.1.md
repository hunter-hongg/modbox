# NAME

modbox-zoxide - Smarter cd command

# SYNOPSIS

**modbox zoxide** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Smarter cd command. This is the modbox implementation of the standard zoxide utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
