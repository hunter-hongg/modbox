# NAME

modbox-realpath - Canonicalize file paths

# SYNOPSIS

**modbox realpath** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Canonicalize file paths. This is the modbox implementation of the standard realpath utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
