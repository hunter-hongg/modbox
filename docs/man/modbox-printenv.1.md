# NAME

modbox-printenv - Print environment variables

# SYNOPSIS

**modbox printenv** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Print environment variables. This is the modbox implementation of the standard printenv utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
