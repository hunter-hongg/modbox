# NAME

modbox-vdir - List directory contents

# SYNOPSIS

**modbox vdir** [*OPTION*]... [*ARG*]...

# DESCRIPTION

List directory contents. This is the modbox implementation of the standard vdir utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
