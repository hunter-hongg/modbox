# NAME

modbox-mkfifo - Make FIFOs

# SYNOPSIS

**modbox mkfifo** [*OPTION*]... [*ARG*]...

# DESCRIPTION

Make FIFOs. This is the modbox implementation of the standard mkfifo utility.

# OPTIONS

`-h`, `--help`
:   Display help and exit.

# EXIT STATUS

`0` on success, non-zero on error.
